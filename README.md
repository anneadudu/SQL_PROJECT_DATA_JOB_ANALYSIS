# SQL Data Analyst Job Analysis

## 📌 Project Overview

This project explores data analyst job postings using SQL to identify trends in job salaries, skills, and demand.

The analysis focuses on remote Data Analyst roles and aims to understand the skills employers are looking for and the skills associated with higher salaries.

## 🎯 Questions Answered

1. What are the top-paying Data Analyst jobs?
2. What skills are required for the top-paying Data Analyst jobs?
3. What are the most in-demand skills for Data Analysts?
4. What are the highest-paying skills for Data Analysts?
5. What are the most optimal skills to learn based on demand and salary?

The project analyzes job postings to identify:
